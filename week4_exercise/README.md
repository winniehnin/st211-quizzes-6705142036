# Week 4 Exercise

This folder contains Python exercises about writing and testing code using pytest.

## Files

### validators.py
Contains functions for validating email addresses and ages.

### test_positive.py
Contains positive tests to check that valid email addresses and ages are accepted.

### test_negative.py
Contains negative tests to check that invalid email addresses and ages raise appropriate errors.

### test_collections.py
Contains tests for Python collections, including lists, dictionaries, and sets.

### test_floats.py
Contains tests for floating-point values.

### shopping.py
Contains the shopping-related program functions.

### test_shopping.py
Contains tests for the functions in shopping.py.
